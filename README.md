# Flask Inventory Management System

## Project Description

A Flask-based REST API inventory management system for an e-commerce administrator portal.

The application allows employees to:
- Add inventory products
- View products
- Update product information
- Delete products
- Search product details using OpenFoodFacts API

---

# Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Migrate
- Marshmallow
- Pytest
- OpenFoodFacts API
- Requests
